## Projects

### OTC Safety Advisor
- **Description**: Built a knowledge-graph grounded QA system for OTC drug and vitamin safety (15+ ingredients, FDA/NIH data) using a hybrid router combining regex, MiniLM, and rapidfuzz with a local Qwen 2.5 7B model via Ollama.
